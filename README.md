# 寶藏小助手

在 **8×8 棋盤**上，根據已挖掘的結果推薦下一個挖掘位置。支援 **1×2、1×3、2×2、3×3** 四種寶藏，長方形可旋轉。

## 使用方式

1. 開啟 `寶藏小助手.exe`，輸入各種寶藏的數量，沒有的種類填 `0`，按「開始」。
2. 參考紅框推薦的位置，在遊戲中挖掘。
3. 點選工具中對應的格子。沒挖到寶藏就按「空格」；找到寶藏則選擇尺寸，以 `◀` / `▶` 切換擺放預覽，確認與實際位置相符後按「確認」。只有一種擺法時會直接記錄。
4. 繼續輸入挖掘結果，推薦位置與剩餘數量會隨之更新。

輸入錯誤可按「上一步」復原。挖掘結果需手動記錄。

## 棋盤標示

| 標示 | 意義 |
| --- | --- |
| 紅框 | 推薦挖掘位置 |
| 白框 | 目前選取的格子 |
| 黃色底色 | 待確認的寶藏位置 |
| 彩色底色與尺寸文字 | 已找到的寶藏 |
| 深灰色底色 | 已確認的空格 |
| 綠框 | 工具推斷的剩餘寶藏位置，僅供參考 |

## 保存進度

按「存檔」保存目前進度，下次開啟時按「載入存檔」繼續。存檔為執行檔旁的 `save.txt`，移動程式時請一併保留。

關閉程式或按「停止」前需手動存檔，再次存檔會覆蓋原有進度。

## 注意事項

- 推薦位置與綠框皆為抽樣估算，不保證命中。
- 出現「找不到合法盤面」時，可能是紀錄有誤或搜尋達到上限，可按「上一步」檢查。
